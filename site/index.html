Microsoft Defender SmartScreen

SmartScreen blocked the installer?

The current Windows installer is not code-signed, so SmartScreen may report it as an unrecognized app.

  1. Verify the download

    Continue only with deejazz-windows-x64.exe downloaded from the official DeeJazz GitHub release.

  2. Open More info

    In the blue SmartScreen window, select More info to reveal the app details and the additional action.

  3. Choose Run anyway

    Confirm the filename, choose Run anyway, and then complete the DeeJazz installer.

Keep SmartScreen enabled. This procedure allows only this downloaded file and does not disable Windows protection.
